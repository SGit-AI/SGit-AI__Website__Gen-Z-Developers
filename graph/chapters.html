ALenses, roles and loops drafting

The second half of the explanation: a prompt is a lens, a role is a model with a description, an agent is a loop with a goal, tools are requests the model sends back, the model remembers nothing, long chats are compressed, so work in focused threads.

Centre of gravity: all three · written first for zara · topics: How to work with agents: briefs, voice, one shared state, Everyone who can brief an agent is a developer now

  • A prompt is a lens: translating into another language is, to a model, the same as explaining for a teenager or a doctor accepted
  • A role is a model with a description and a question; an agent is that role on a loop with a goal accepted
  • Tools changed everything: the model answers with a request, the program runs it, and the result goes into the next request accepted
  • The model remembers nothing between requests: every request carries the whole conversation, which is why there is a context window accepted
  • Long chats are compressed into a lower-resolution summary, so details drop out: work in many focused threads with named agents accepted
