Reach is a computed value, and new capability lands as excess, never as new authority

What an agent can reach is not a document but the output of a calculation, so the question to answer is what calculates it and whether that is a one-time snapshot or wired to the pipeline. When a connector or integration is added the reach grows, the gap recomputes and a re-review follows; the mandate is locked business logic that changes only through change control, so a new capability can only land in the gap as excess, never as new authority. Unbounded includes volume: an agent permitted £10k per action that can perform a thousand actions carries a £10m exposure.

Decided by. Nobody yet: a candidate for Dinis to read, comment on and decide (keep, rewrite, merge, cut, article first, later, not doing it).

Note. Status in the article: MVPs and proofs of concept, complete for simple single-agent deployments. The question's example is in dollars ($25k cap, $75k order) and the answer's in pounds (£10k mandate, £100k reach); the book should pick one currency.
