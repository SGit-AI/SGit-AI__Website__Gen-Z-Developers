The file system is the database: load, extract, transform, save, and keep every intermediate as a file

A database server is a large, stateful, always-on thing to provision, secure, back up and pay for, and most of what it holds would be happy as files. LETS loads state, works on it and saves every stage back as files you can version, diff and read: a cache, a database and an audit trail in one, with git as its history. Two real database engines now run in the reader's browser over the site's own JSON.

Decided by. Nobody yet: a candidate for Dinis to read, comment on and decide (keep, rewrite, merge, cut, article first, later, not doing it).
