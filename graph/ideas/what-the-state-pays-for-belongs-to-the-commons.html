No sovereignty without open source and open schemas; what the state pays for belongs to the commons; buy the alternative before the day you need it

Sovereignty means you can leave: a road with a toll gate owned by one company is lock-in with tarmac, and independence is the ability to run a parallel service, move the data and keep going, which exists only if the code and the schemas are open. What the public paid for should be available to the public, not so everyone changes the production system but so everyone can see it, run it and leave with their data, which is also how the local industry around it comes into being. And a market for the alternative does not appear on the day the single point of failure fails: run parallel services, buy the local or open alternative for part of the estate now and accept fewer features, and use procurement, the lever a state already holds, to prefer open schemas and data mobility.

Decided by. Nobody yet: a candidate for Dinis to read, comment on and decide (keep, rewrite, merge, cut, article first, later, not doing it).

Note. The five-move playbook: map the attrition, commoditise the plumbing, create the demand, put the money where the market is genesis, regulate what settled, then map again. hack-your-country already cites sovereignty-is-the-ability-to-move for the test; this is the civic argument behind it, and the resilience case rather than an ideological one.
