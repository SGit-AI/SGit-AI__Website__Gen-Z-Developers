Memory is not a spectator sport: it is context management, many memories, fractal, published and shared

The industry's picture is one store everything is pumped into and retrieved from by similarity. Dinis's is the opposite: memory is deciding what an agent needs in its window now, and no more, because context costs tokens and attention; it is many memories, each with its own vocabulary; it is fractal, principles in a few kilobytes at the top and code at the bottom; it is published and open so an agent can fetch, quote and cite; and it is shared through vaults so a session can end and the next picks up from the same files. The field arrived at files too: a plain filesystem beat a graph memory on the benchmark.

Decided by. Nobody yet: a candidate for Dinis to read, comment on and decide (keep, rewrite, merge, cut, article first, later, not doing it).

Note. The thesis calls itself untested and falsifiable; the article lists what does not exist yet (a second estate, a freshness check, a published hand-off shape).
