A change decided by precedent goes on a list Dinis can overturn, and Dinis reads the diffs of the book

Two safeguards instead of a yes on everything: the list of changes decided by precedent, which Dinis can overturn (overturning makes a new precedent), and the diff, because every release candidate is a diff against the one before and Dinis reads them, so nothing changes unseen. The editor makes each candidate's diff readable on its own: what changed, which hearing or precedent changed it.
