'Nobody knows how it is built' is fixable: make the agents leave a record, a mandate, a memory and a graph

HBR's warning that the AI designs the architecture so nobody in-house knows how the tool is built is true of most agent-built software today and does not have to be. If the agents work under a written mandate, keep their memory in a versioned store the company owns, and describe what they built as a graph, the architecture is a record the next team can read, not a mystery. A prototype ready for the villagers looks like Mondweep Chakravorty's SGit and Ruflo run: versions pinned, sixteen tests, a folder of evidence, a written behaviour policy, and a README that says plainly what it does not do yet.

Decided by. Nobody yet: a candidate for Dinis to read, comment on and decide (keep, rewrite, merge, cut, article first, later, not doing it).

Note. The article says the record is a proposal, not a standard: this site runs it; few organisations do yet. Dinis declares a stake: his companies sell open source and this kind of record.
