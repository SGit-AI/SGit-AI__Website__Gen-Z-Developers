# Every change is minor, unless Dinis says it is major

**Decided.** 2026-10-18

**By.** Dinis Cruz.

**Said.** "Every change should be minor, unless I say it's a major one."

**Means.** Versions here are `v{release}.{major}.{minor}`, the names this repository's release pipeline already uses. Every change, to the site or to the book, bumps the last number. The middle number moves only when Dinis says a change is major, and the first only for a new edition of the book (the second edition is book v2.0.0, when Dinis says so). An agent never chooses a major on its own: the site's next release after v0.2.1 is v0.2.2, and the book's next signed-off version after v1.0.0 is v1.0.1.

**Supersedes.** The "deliberate .0 minor" in `CLAUDE.md`'s release ritual, and "a change to the text is the next minor version" in `admin/content/book/versions.json`, both read as allowing an agent to choose the middle number.
