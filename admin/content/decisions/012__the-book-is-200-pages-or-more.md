# The book is 200 pages or more

**Decided.** 2026-10-19

**By.** Dinis Cruz.

**Said.** "The book actually should be, you know, much bigger. I think, in a way, that book was quite thin. We need to easily, you know, we should be hitting the 200 plus pages."

**Means.** The second edition's target is 200 printed pages or more; the 2018 paperback was 139. The review board's cutter still argues against every addition, and the default answer is still no, but its budget is a book of 200 pages and more, not the first edition's length: the question for a proposal is whether it earns its place, not whether the book is already long enough. Short and punchy stays the rule for chapters, not for the book.

**Supersedes.** Nothing; it answers the second question kept apart in [the book in release mode](/articles/the-book-in-release-mode.md).
