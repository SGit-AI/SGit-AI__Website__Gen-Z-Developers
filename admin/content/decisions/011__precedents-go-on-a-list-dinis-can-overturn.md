# Precedents go on a list Dinis can overturn, and Dinis reads the diffs

**Decided.** 2026-10-19

**By.** Dinis Cruz.

**Said.** "Yes, the list can overturn. And basically, you have to remember that I would also be reading the diffs, right, of the book, which is a very important concept here. So I can keep an eye on it."

**Means.** A change the review board decides by precedent does not wait for Dinis's yes: the editor applies it and it goes on a list Dinis reads and can overturn, and overturning makes a new precedent (decision 008). The second safeguard is the diff: every release candidate is a diff against the one before, and Dinis reads the diffs of the book, so nothing changes in it unseen. The editor makes each release candidate's diff readable on its own: what changed, which hearing or precedent changed it.

**Supersedes.** Nothing; it answers the first question kept apart in [the book in release mode](/articles/the-book-in-release-mode.md).
