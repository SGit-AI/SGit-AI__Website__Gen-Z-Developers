# Every format from one source

**Decided.** 2026-10-18

**By.** Dinis Cruz.

**Said.** "I would like to create them all here from the same source."

**Means.** The print PDF, the screen PDF, the EPUB, and whatever Kindle needs, are all built in this repository from the same frozen text, by the same build, with the same stamp and manifest. None is made by hand or by a store's converter. Dinis remembered Leanpub wanting MOBI; which formats each store accepts today is for the publisher to check and record before building (Amazon's own guidance for new Kindle ebooks is the source to read, not memory).

**Supersedes.** Nothing; it extends [release the book we already released](/articles/release-the-book-we-already-released.md), which left the EPUB slot empty.

**Recorded in.** [Dinis's first decisions](/agent-articles/dinis-first-decisions.md).
