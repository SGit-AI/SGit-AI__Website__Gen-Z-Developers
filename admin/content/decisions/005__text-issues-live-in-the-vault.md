# Text issues live in the vault

**Decided.** 2026-10-18

**By.** Dinis Cruz.

**Said.** "For now, all the text issues we'll leave in our vault. So we're going to move into the vault, and we can start with that V2.0, because it's just been released."

**Means.** Every issue about the book's text (a finding, a reader's comment, a 2018 GitHub issue, Dinis's comments and decisions on an item) is a file in the public vault, under `board/`, not in this repository. The work issues of the roles stay in `team/<role>/issues/`, and the decisions on how the book is made stay here, on [the decisions page](/decisions/index.html). The working copy starts from the book as site v0.2.0 froze it: v1.0.0, the published book, 28 chapters. The site's board, when it is built, shows the roles' work issues; the vault's board is the view of the text issues.

**Supersedes.** "Where content issues live" in [one board for the book](/articles/one-board-for-the-book.md), which proposed `board/content/` in this repository.

**Recorded in.** [Dinis's first decisions](/agent-articles/dinis-first-decisions.md). The reading of "V2.0" as site v0.2.0 is the journalist's; Dinis to confirm.
