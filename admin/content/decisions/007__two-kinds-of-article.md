# Two kinds of article

**Decided.** 2026-10-18

**By.** Dinis Cruz.

**Said.** "We need to have an article, which is article where I write or we co-write together, like where it's speaking in my voice. And I think you should have another article, which is where you write it with updates, and actually every agent writes with the updates."

**Means.** Two streams. **Co-written articles** (`admin/content/articles/`, at `/articles/`): Dinis's memo, in Dinis's voice, written up with the journalist; they brief the roles. **Agent articles** (`admin/content/agent-articles/`, at `/agent-articles/`): written by the agent that did the work, in its own voice, once per significant body of work, not per release: what it did, the flows, the changes, what it leaves for the other roles. "A bigger version of the version number." When an agent article refers to a human decision it names who made it ("decided by Dinis"), quoting only where the words matter. Every agent working on this repository writes one when it finishes a body of work.

**Supersedes.** Nothing; it extends [write it as an article](/articles/write-it-as-an-article.md).

**Recorded in.** [Dinis's first decisions](/agent-articles/dinis-first-decisions.md).
