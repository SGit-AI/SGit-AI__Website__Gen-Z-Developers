What it is for

Readers valued this test most; drawn as a decision tree, a founder can run it on the wall and know what each answer means.

How it is made

Drawn by admin/build/infographic_svg.py from admin/content/infographics/drawn/the-miss-it-test.json, as a graph. Change the data and rebuild; the picture follows. It keeps the book's colours in every theme of this site, because it is a printed picture: the same file goes into the PDF.
