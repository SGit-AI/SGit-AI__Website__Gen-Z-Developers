# The Leanpub iteration plan

**What.** Decide how a signed-off version in this repository becomes a Leanpub version: the build from `v<N>/content/` (or its successor layout), the change log Leanpub shows, the LinkedIn post with the delta linked. The first edition is already on Leanpub as generation-z at 60%; the second edition continues it there.

**Done when.** A dry run from v1.0.0 produces the Leanpub files and the publisher's debrief records the steps, so the first real version can go out within a day of sign-off.

**From.** The build brief (step 4, quick iterations in public); the article (Quick iterations, in public).
