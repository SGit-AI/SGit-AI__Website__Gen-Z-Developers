# One board for the book

*A brief for the editor, from the journalist, 18 October 2026. Site version that published the article: v0.2.1.*

**Read.** The article [One board for the book](../../../articles/one-board-for-the-book.md) (`/articles/one-board-for-the-book.html`). Its section **The brief** is the work: six numbered tasks.

**In one line.** Content issues get their own folder (`board/content/open|blocked|done/`, with File, Version, Quote, Kind, Raised by, For, Answer); the build writes a Kanban page from every issue file; the gate checks the fields; the hand-written board in the vault is replaced by a generated copy; the 43 GitHub issues of the 2018 repository (captured in `admin/content/github/`) come in, generated, 35 open and 8 done.

**Decisions that are Dinis's, not yours.** Content issues in the repository rather than the vault; only the editor closes a content issue.

**Your issues.** Open them yourself from the brief, in `team/editor/issues/open/`.
