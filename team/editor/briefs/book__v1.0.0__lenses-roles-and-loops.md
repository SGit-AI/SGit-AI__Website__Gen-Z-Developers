# Lenses, roles and loops: how LLMs and agents work

*A brief for the editor, from the journalist, 18 October 2026. Book version: v1.0.0. Site version that published the article: v0.2.14.*

**Read.** The article [Lenses, roles and loops](../../../articles/lenses-roles-and-loops.md) (`/articles/lenses-roles-and-loops.html`) and its [storyboard](../../../storyboards/lenses-roles-and-loops.html). The article's brief, tasks 1 to 4, is yours.

**In one line.** The second half of the generative AI chapter: a prompt is a lens (translating into a language and for an audience are the same act to a model, and "bad at maths" is often the wrong lens); a role is a model with a description and a question; an agent is that role on a loop with a goal; tools are requests the model sends back, run by the harness and resent with the next request; the model remembers nothing, which is why there is a context window; long chats are compressed and lose detail (the newsroom's eighteen summaries at 1.7%); so work in many focused, named threads that talk through files. Place the chapter right after generative AI, plan the lenses exercise and a tiny agent loop for the hands-on part, and write the interview questions. The article's "Precisely" section is the technical floor the chapter must not go below.
