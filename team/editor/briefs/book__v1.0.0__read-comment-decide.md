**In one line.** On the editor's desk (`/read/`, site v0.2.0), Dinis reads an item, comments in Dinis's own words, and picks a verb (keep, fix, rewrite, merge into, cut, article first, later, not doing it); you record it in the vault, at `board/decisions/NNN__<slug>.md`, with the comment verbatim, act on it in the vault's working copy, and say where. The desk gets a decision per chapter, kept in the browser and carried in the export; nothing is sent. First batch: the five `show-in-book` GitHub issues and the four Introduction chapters, then a debrief stamped `book__v1.0.0__decisions-01.md`.

**Depends on.** *Everything unfinished in one place*, for the inventory; the first batch can run before it, from a hand-picked page of nine items.

**Decisions that are Dinis's, not yours.** Every decision in the loop; memo per item or per sitting; nothing on version numbers: decision 006 makes the first signed-off change v1.0.1, and only Dinis declares a major.
