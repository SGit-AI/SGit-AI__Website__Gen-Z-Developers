# Read, comment, decide

*A brief for the editor, from the journalist, 18 October 2026. Book version: v1.0.0. Site version that published the article: v0.2.1.*

**Read.** The article [Read, comment, decide](../../../articles/read-comment-decide.md) (`/articles/read-comment-decide.html`). Its section **The brief** is the work: six numbered tasks.

**In one line.** On the editor's desk (`/read/`, site v0.2.0), Dinis reads an item, comments in Dinis's own words, and picks a verb (keep, fix, rewrite, merge into, cut, article first, later, not doing it); you record it in `team/editor/decisions/NNN__<slug>.md` with the comment verbatim, act on it in the vault's working copy, and say where. The desk gets a decision per chapter, kept in the browser and carried in the export; nothing is sent. First batch: the five `show-in-book` GitHub issues and the four Introduction chapters, then a debrief stamped `book__v1.0.0__decisions-01.md`.

**Depends on.** *Everything unfinished in one place*, for the inventory; the first batch can run before it, from a hand-picked page of nine items.

**Decisions that are Dinis's, not yours.** Every decision in the loop; memo per item or per sitting; whether the first signed-off change is v1.1.0 or the start of the second edition.
