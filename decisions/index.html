001 · The 2018 text is Creative Commons BY

Decided. 2026-10-18

By. Dinis Cruz, in a voice memo to the session running as the journalist.

Said. "The license of this is going to be this as before, CC by, Creative Commons by."

Means. The text of Generation Z Developers is CC BY 4.0, as the 2018 cover and Introduction said. The CC BY-SA line in the 2018 footer and the Apache 2.0 file in the 2018 repository are the exceptions, explained, not followed. The site's footer says CC BY; the print and screen editions get a copyright page that says CC BY 4.0. The reviewer closes its blocked issue 004__settle-the-licence-of-the-2018-text.md against this record.

Supersedes. The open question in the build brief and in release the book we already released.

Recorded in. Dinis's first decisions.

002 · Leanpub gets our own PDF, built here and matched to the 2018 one

Decided. 2026-10-18

By. Dinis Cruz.

Said. "I want to try to upload LeanPub, the print PDF. I want to see if that can work. So we can do everything here." And: "compare with the print PDF created by LeanPub, and we should be able to match it here."

Means. The publisher builds the PDF in this repository, with the print workflow the graphs books used (WeasyPrint, 6 by 9, the bookkit), compares it page by page with the 2018 file Leanpub made (v1/generation-z-print-ready.pdf, 139 pages), and keeps going until it matches: same chapters, same order, close to the same pages. Leanpub is switched to uploaded files. Then the same goes to Amazon KDP. Whether Leanpub's PDF must differ from the print one (Leanpub's buyers read on screens; the paperback is printed) is for the publisher to find out and report, not to assume.

Supersedes. "Release one" in release the book we already released, the 2018 interior uploaded untouched: the first release is now the one built here.

Recorded in. Dinis's first decisions.

003 · Every format from one source

Decided. 2026-10-18

By. Dinis Cruz.

Said. "I would like to create them all here from the same source."

Means. The print PDF, the screen PDF, the EPUB, and whatever Kindle needs, are all built in this repository from the same frozen text, by the same build, with the same stamp and manifest. None is made by hand or by a store's converter. Dinis remembered Leanpub wanting MOBI; which formats each store accepts today is for the publisher to check and record before building (Amazon's own guidance for new Kindle ebooks is the source to read, not memory).

Supersedes. Nothing; it extends release the book we already released, which left the EPUB slot empty.

Recorded in. Dinis's first decisions.

005 · Text issues live in the vault

Decided. 2026-10-18

By. Dinis Cruz.

Said. "For now, all the text issues we'll leave in our vault. So we're going to move into the vault, and we can start with that V2.0, because it's just been released."

Means. Every issue about the book's text (a finding, a reader's comment, a 2018 GitHub issue, Dinis's comments and decisions on an item) is a file in the public vault, under board/, not in this repository. The work issues of the roles stay in team/<role>/issues/, and the decisions on how the book is made stay here, on the decisions page. The working copy starts from the book as site v0.2.0 froze it: v1.0.0, the published book, 28 chapters. The site's board, when it is built, shows the roles' work issues; the vault's board is the view of the text issues.

Supersedes. "Where content issues live" in one board for the book, which proposed board/content/ in this repository.

Recorded in. Dinis's first decisions. The reading of "V2.0" as site v0.2.0 is the journalist's; Dinis to confirm.

006 · Every change is minor, unless Dinis says it is major

Decided. 2026-10-18

By. Dinis Cruz.

Said. "Every change should be minor, unless I say it's a major one."

Means. Versions here are v{release}.{major}.{minor}, the names this repository's release pipeline already uses. Every change, to the site or to the book, bumps the last number. The middle number moves only when Dinis says a change is major, and the first only for a new edition of the book (the second edition is book v2.0.0, when Dinis says so). An agent never chooses a major on its own: the site's next release after v0.2.1 is v0.2.2, and the book's next signed-off version after v1.0.0 is v1.0.1.

Supersedes. The "deliberate .0 minor" in CLAUDE.md's release ritual, and "a change to the text is the next minor version" in admin/content/book/versions.json, both read as allowing an agent to choose the middle number.

Recorded in. Dinis's first decisions.

007 · Two kinds of article

Decided. 2026-10-18

By. Dinis Cruz.

Said. "We need to have an article, which is article where I write or we co-write together, like where it's speaking in my voice. And I think you should have another article, which is where you write it with updates, and actually every agent writes with the updates."

Means. Two streams. Co-written articles (admin/content/articles/, at /articles/): Dinis's memo, in Dinis's voice, written up with the journalist; they brief the roles. Agent articles (admin/content/agent-articles/, at /agent-articles/): written by the agent that did the work, in its own voice, once per significant body of work, not per release: what it did, the flows, the changes, what it leaves for the other roles. "A bigger version of the version number." When an agent article refers to a human decision it names who made it ("decided by Dinis"), quoting only where the words matter. Every agent working on this repository writes one when it finishes a body of work.

Supersedes. Nothing; it extends write it as an article.

Recorded in. Dinis's first decisions.
