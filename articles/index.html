Articles

This site’s own articles, in reading order. They are how Dinis briefs the roles that finish the book: an idea, a task or a review is researched, mapped and written up as an article, in Dinis’s voice, before any role acts on it; a role is then pointed at the article and takes it from there. The shape and the voice are the newsroom’s (how the voice works).

  1. Write it as an article: how I brief the agents that finish this book, and why their first job is to ship the book we already shipped (2026-10-18, site v0.2.1)
  2. Release the book we already released: v1.0.0 end to end, first with the 2018 print file and a new cover, then built from this repository, before a word of it changes (2026-10-18, site v0.2.1)
  3. One board for the book: every issue a file, a Kanban page built from the files, and every content issue pinned to a version and a sentence (2026-10-18, site v0.2.1)
  4. Everything unfinished in one place: the outlines, the drafts, the 2018 GitHub issues and my handwritten notes, as one inventory I can read through and decide on (2026-10-18, site v0.2.1)
  5. Read, comment, decide: how I go through the pile, one item at a time, and how the editor turns my decisions into the next version of the book (2026-10-18, site v0.2.1)

The sources are in admin/content/articles/; each page links its markdown twin, which is the file to hand to an agent. The journalist’s mandate is its role.
