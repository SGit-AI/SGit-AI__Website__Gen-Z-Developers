QR codes

The book's QR codes. Each code prints a short, stable address on this site, gen-z-developers.sgit.ai/q/<id>/, and that page sends the reader on to the target, so a printed code never goes out of date: the target changes here, the paper does not. Proposed by the journalist on 19 October 2026 from Dinis's memo on QR codes (RC2 on paper, part 3); the first ids are the links page 12 of rc2 asks for. The build writes each q/<id>/index.html; admin/build/qr_codes.py (needs segno) draws each q/<id>/qr.svg once.
