The versions of the book

The rule this site is built on: the repository holds the official versions; the vault holds the working versions. A version moves from the vault into the repository when it is signed off, on top of the one before, and this page shows the delta between every two versions, block by block and word by word. There is one version so far.

The table and the deltas are computed by the newsroom's page_versions.py (newsroom v0.12.113), copied into admin/build/ as the brief asked rather than rewritten. Each version is frozen as one markdown file by the release that made it and never rewritten; the frozen file for v1.0.0 is v1.0.0.md, 41,843 words in 2,284 blocks.

Where v1.0.0 comes from

  • The repository DinisCruz/Book_Generation_Z_Developer at commit 61886444fe5a (1 March 2024, a README change; the content was last changed in October 2018). Its content/ folder is copied verbatim to v1/content/ and its static/images/ to v1/images/: 138 markdown files, 90 of them outlines.
  • Leanpub: "Key concepts and ideas for the next generation of developers", 60% complete, 136 pages, 30,695 words, last updated 8 October 2018, 465 readers (read 18 October 2026). The Leanpub build left the outlines out; this site shows them, because the second edition starts from them.
  • Amazon: Gen Z Developers, the paperback: 139 pages, published 30 September 2018, ISBN-10 1724194607, the early-release cover of September 2018 with its eight lines. That publication date is the date of v1.0.0; 8 October 2018 is the last change to the text, on Leanpub and in the repository.
